# OpportuneX

OpportuneX is a full-featured web application that helps users explore, apply for, and manage job opportunities efficiently. It features a clean, responsive interface and practical tools for both job seekers and companies.

## Key Features

- Browse and search job opportunities with filters
- Apply for jobs and track application status
- User profile management and update options
- Company admin features to manage jobs and applicants
- Responsive and professional UI built with React and Shadcn UI
- Smooth animations and protected routes for better UX

## Technologies Used

- Frontend: React (Vite)
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT
- Git & GitHub for version control

## About
  This project demonstrates full-stack development skills including frontend UI design, backend API development, state management, database integration, and user authentication.
